# FlowPad — one-click token launchpad (Base + Robinhood Chain)

> "FlowPad" is a placeholder brand. Change it with `NEXT_PUBLIC_APP_NAME`.

Anyone can launch a coin in one transaction. Every coin trades instantly on **Uniswap v4**. Every trade pays a **1% fee in ETH**: **50% goes to the coin's creator** and **50% to the platform**. It works like [Klik](https://klik.finance), with a better deal for creators and on-chain safety guarantees.

| | Klik | This project |
| --- | --- | --- |
| Swap fee | 1% (60% platform / 40% creator) | 1% (50% platform / **50% creator**) |
| Liquidity | locked | **locked by code**: the factory has no removal function |
| Supply / taxes | fixed | fixed 1B, **no owner, mint, tax, blacklist or pause** |
| Fee changes | – | **frozen per pool at launch**; global hard cap 2% |
| Anti-snipe | yes | launch-second lock + max 1% per wallet for 60 s |
| Creator buy at launch | – | optional, **capped at 5%** and shown on the coin page |
| Selling UX | approve + swap | **1 signature + 1 tx** (tokens pre-approve Permit2) |
| Fee rights | – | **transferable** (community takeover) |
| Referrals | – | **20% of the platform's half** to whoever brought the trader, sticky on-chain |
| Languages | EN | **EN / RO** |

## How the money works

```
revenue = trading volume × 1% × 50%      (× 80% on volume from referred traders)
```

| Daily volume | Fees generated | Your share (platform) | Creators' share |
| ---: | ---: | ---: | ---: |
| $100k | $1,000 | $500/day | $500/day |
| $1M | $10,000 | $5,000/day | $5,000/day |

Fees accrue as ETH inside the `FeeHook`. Anyone can call `claimProtocolFees()`, and the money always goes to the factory's `treasury` (use a Safe multisig). Creators claim from their profile page.

**Referrals.** Every profile has a referral link (`/?ref=0x…`). The app remembers the first link a browser opened and sends it with every trade. On-chain, the first valid referrer a wallet trades with is stored in `FeeHook.referrerOf` and kept for good. From then on that referrer gets `referralShareBps` (default 20%, max 50%, frozen per pool at launch) of the platform's half of each fee: 0.1% of the trader's volume. The creator's 50% never changes and the trader pays nothing extra. Referrers claim from their profile, like creators.

Optional extra lever: `creationFee` (a flat ETH fee per launch, max 0.05 ETH, default 0).

## Architecture

```
            ┌────────────── web (Next.js 16, wagmi, RainbowKit) ──────────────┐
            │  /create  /token/[chain]/[address]  /profile/[address]  /how-it-works │
            └──────┬──────────────────────────────┬──────────────────────────┘
                   │ tx (launch / buy / sell / claim)│ REST (tokens, trades, candles…)
                   ▼                                 ▼
 ┌──────────── contracts (Foundry) ────────────┐   ┌──── indexer (Ponder) ────┐
 │ LaunchFactory ─ creates ─▶ LaunchToken       │   │ TokenLaunched, Trade,    │
 │      │ initialize + lock liquidity           │──▶│ Transfer, FeesClaimed →  │
 │      ▼                                        │   │ tokens, trades, candles, │
 │ Uniswap v4 PoolManager ◀── FeeHook (1% ETH)   │   │ holders (PGlite/Postgres)│
 │      ▲                                        │   └──────────────────────────┘
 │ LaunchRouter (buy / sell / quote)             │
 └───────────────────────────────────────────────┘
```

- `contracts/`: Solidity 0.8.26, Uniswap v4 core and periphery, Solady. 66 unit, fuzz and invariant tests, plus fork tests against the real Base Sepolia and Robinhood Chain PoolManagers.
- `indexer/`: Ponder 0.17 indexes the factory, the hook and every token (holders), and serves a REST API.
- `web/`: Next.js 16, Tailwind 4 and shadcn/ui. The look comes from CoinFlow: indigo theme, sidebar layout, EN/RO, dark/light.
- `shared/`: ABIs, deployment addresses, chains and math shared by the indexer and web. Generated by `npm run gen`.

**Price curve:** the whole supply sits in one Uniswap v4 range above the start price. Buying Δ ETH (after fees) moves the fully-diluted market cap from F to about **F·(1 + Δ/F)²**. With the default F = 1.5 ETH, 1.5 ETH of buys makes it 4×.

## Run everything locally

Requirements: Node 22+, Git, [Foundry](https://getfoundry.sh) (`curl -L https://foundry.paradigm.xyz | bash` then `foundryup`; on Windows run these in Git Bash).

```bash
git clone --recursive https://github.com/pocapoc2001/App1Crypto.git && cd App1Crypto
npm install
cp web/.env.example web/.env.local      # defaults point at the local chain
```

Use four terminals:

```bash
npm run dev:chain      # 1. local chain (anvil, chain id 1337)
npm run dev:deploy     # 2. deploy contracts + regenerate shared/ (run once per fresh chain)
npm run dev:indexer    # 3. indexer API on http://127.0.0.1:42069
npm run dev:web        # 4. app on http://localhost:3000
```

In the app, choose **Connect Wallet → "Anvil test wallet (local)"**. It signs with anvil's public test account #0, the same well-known key the `dev:deploy` script uses. It only exists for the local chain, so never send real funds to it. You can also add `http://127.0.0.1:8545` (chain 1337) to MetaMask and import an anvil test key.

> If you restart anvil, run `npm run dev:deploy` again and delete `indexer/.ponder/` so the indexer starts fresh.

## Deploy to a testnet (Base Sepolia)

1. Create a **testnet-only** wallet: `cast wallet new`. Fund it from a Base Sepolia faucet.
2. Deploy:
   ```bash
   cd contracts
   forge script script/Deploy.s.sol --rpc-url base_sepolia --broadcast --private-key <TESTNET_KEY>
   cd .. && npm run gen
   ```
3. Indexer: `PONDER_CHAINS=baseSepolia npm run dev:indexer` (set `PONDER_RPC_URL_84532` to an Alchemy URL for reliability).
4. Web: set `NEXT_PUBLIC_CHAINS=baseSepolia` in `web/.env.local`, then run `npm run dev:web` and use MetaMask on Base Sepolia.

Robinhood Chain testnet has no Uniswap v4, so the deploy script deploys a fresh PoolManager there (`robinhood_testnet` alias). Robinhood **mainnet** (4663) and Base mainnet use the canonical Uniswap v4 addresses in `contracts/script/chains.json`.

## Before real money (mainnet checklist)

- [ ] **Professional smart-contract audit** of `FeeHook`, `LaunchFactory` and `LaunchRouter`, or a competitive audit contest. Bugs here can lose user funds.
- [ ] `OWNER` and `TREASURY` set to a **Safe multisig**, not a hot wallet.
- [ ] Deploy with a hardware wallet or keystore (`--account`), never a raw key in `.env`.
- [ ] `PINATA_JWT` set (IPFS storage for images and metadata). Local uploads are dev-only.
- [ ] Paid RPC (Alchemy or QuickNode) for the indexer and web; Postgres (`DATABASE_URL`) for Ponder.
- [ ] Rate-limit `/api/upload` (for example via your hosting provider's WAF).
- [ ] Legal: talk to a crypto lawyer in your jurisdiction (MiCA in the EU, consumer protection, tax on fee income). Set up a company, terms of service, and geo-blocking where required.
- [ ] Set `startingMarketCap` per chain in `chains.json` based on the ETH price at launch.

## Security notes

- The hook takes fees only in ETH. Fees are snapshotted per pool and capped at 2% in code.
- The factory can't remove liquidity, and tokens have no privileged roles.
- `/api/metadata` only fetches from the IPFS gateway or local uploads, never arbitrary URLs (SSRF protection). Metadata links are rendered only if they're http(s).
- Anti-snipe uses `block.timestamp`, because on Arbitrum-stack chains like Robinhood `block.number` is an L1 block number. It keys on `tx.origin`, which is a speed bump, not a guarantee.
- Referral bindings also key on `tx.origin`, so any contract a wallet calls can name that wallet's first referrer, and smart-contract wallets share their bundler's binding. This can only redirect part of the platform's own cut: what traders pay and what creators earn never change. The hook ignores malformed `hookData` instead of reverting, so third-party routers keep working.
